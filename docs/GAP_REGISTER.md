## Original project review findings

| Finding | Mitigation and verification |
|---|---|
| Blocked payments counted against spend | The budget counts ledger reservations and captures. The [HTTP quickstart](../backend/tests/test_developer_quickstart.py) checks that blocks and unresolved holds leave allowance unchanged. Capture moves a reservation into the captured total. |
| Merchant formatting made policy checks inconsistent | Policy and scoring use the same normalized names. Production requests bind to owner-scoped merchant records with canonical attributes. The [quickstart](DEVELOPER_QUICKSTART.md) exercises both formatting and stable IDs. |
| Quotas could vary per replica | The production profile uses a shared Redis quota and rejects API work when Redis is unavailable. [Redis tests](../backend/tests/test_rate_limit_shared.py) check enforcement and retry timing. [Compose acceptance](../scripts/container_acceptance.py) checks quota outage and recovery. |
| Production credential authority was incomplete | PostgreSQL stores scoped credential authority. [Authority tests](../backend/tests/test_shared_authority.py) cover rotation, revocation, expiry and queued work. Customer sign-in through a deployment identity provider is optional under G01. |
| Human review had no path into evaluation | The [feedback workflow](FEEDBACK_EVALUATION.md) exports review cases for independent labeling, replays observed ledger state and evaluates threshold proposals on later cases. Representative labels and live model evidence remain under G07. Policy and model behavior change only through a separate reviewed update. |
